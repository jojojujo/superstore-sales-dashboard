 Superstore Sales Dashboard (Power BI)

## 📊 Overview
This project presents an interactive sales dashboard built using Microsoft Power BI to analyze Superstore data across the United States for the years 2019 and 2020.

## 🚀 Key Features
- Year-wise sales and profit comparison
- Region-wise performance analysis
- Category and sub-category insights
- Sales distribution by payment mode and shipping method
- Interactive filtering (Central, East, South, West)

## 📈 Key Insights
- Total sales reached **1.6M** with a total profit of **175K**
- Sales and profit in **2020 exceeded 2019**
- **Cash on Delivery (COD)** was the most used payment method
- The **Western region** contributed the highest sales
- Top-performing categories: **Office Supplies and Phones**
- **California** recorded the highest sales among all states
